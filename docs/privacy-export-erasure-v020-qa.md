# SportIQ Account Privacy 0.2.0 스테이징 배포·검증

## 현재 상태
- GitHub: `wordpress/sportiq-account-privacy/sportiq-account-privacy.php` 버전 0.2.0
- WordPress 스테이징: 버전 0.1.0 활성 (배포 전 확인)
- 개인정보 요청 페이지: ID 52, 비공개
- 개인정보 요청 접수 E2E: 미실시
- 내보내기·삭제 E2E: 미실시

## 배포 절차
1. GitHub에서 최신 PHP 파일을 가져온다.
2. `sportiq-account-privacy/sportiq-account-privacy.php` 구조로 ZIP을 만든다.
3. `php -l`로 PHP 구문 검사한다.
4. WordPress 스테이징의 플러그인 업로드에서 기존 플러그인을 덮어쓰는 방식으로 설치한다.
5. 플러그인 목록에서 **0.2.0 활성** 여부를 확인한다.
6. 개인정보 요청 페이지는 비공개로 유지한다.

## 안전한 테스트
- 별도 스테이징 회원 A/B를 준비하고 실제 이용 회원은 사용하지 않는다.
- 회원 A에만 관심 팀·리그를 저장한다.
- WordPress 도구 > 개인정보 내보내기에서 A의 이메일을 대상으로 확인 절차를 진행하고, SportIQ 관심 목록 항목이 포함되는지 검증한다.
- B의 내보내기 결과에는 A의 관심 목록이 없어야 한다.
- WordPress 도구 > 개인정보 삭제에서 **전용 테스트 계정 A만** 처리한다.
- 삭제 처리 전 백업과 대상 이메일·계정을 이중 확인한다.
- A의 `sportiq_favorites_v1` 메타가 삭제됐는지 확인하고 B의 데이터가 유지되는지 확인한다.
- 삭제 요청 폼 제출만으로는 어떤 데이터도 삭제되지 않는지 확인한다.

## 알려진 제약
- WordPress 코어의 개인정보 삭제 도구는 계정 자체 삭제와 별개일 수 있다.
- SportIQ 0.2.0 eraser는 `sportiq_favorites_v1` 메타만 삭제하며 계정을 삭제하지 않는다.
- 삭제한 사용자 메타는 복구가 어려울 수 있으므로 실사용 계정 테스트 금지.
- 플러그인의 데이터 구조에 따라 내보내기 표시 형식이 달라질 수 있어 실제 출력 검증 필요.
- 개인정보처리방침 및 회사 연락처 미확정으로 공개 출시 금지.
