# SportIQ 개인정보 요청 플러그인 스테이징 QA

## 배포 상태
- 코드: wordpress/sportiq-account-privacy/sportiq-account-privacy.php
- WordPress 페이지 ID 52: 비공개 초안
- 플러그인 설치/활성화: 미완료
- 실사용 회원 계정 및 개인정보: 변경하지 않음

## 설치 전 점검
1. PHP 구문 검사 `php -l`
2. `sportiq-account-privacy/` 폴더를 포함하는 ZIP 생성
3. WordPress 스테이징에 ZIP 업로드 및 활성화
4. shortcode `[sportiq_privacy_request]` 출력 확인

## 기능 QA (실제 테스트 필요)
- 비로그인 접근: 로그인 안내만 표시, 접수 불가
- 회원 A: 열람 요청 1회 제출, 관리자 전용 요청 기록 생성
- 같은 회원 1시간 이내 재요청: 제한 메시지
- 회원 B: A의 요청 기록을 열람할 수 없어야 함
- CSRF nonce 변조: 접수 거부
- 임의의 요청 유형: 접수 거부
- 요청 제출 후 회원 계정/관심 목록: 변경 없음
- 관리자: 요청을 조회하고 운영 절차에 따라 수동 처리

## 출시 차단 사항
- 자동 개인정보 내보내기/삭제 처리 미구현
- 본인 확인·처리 완료 통지 및 기록 보존 절차 미확정
- 개인정보처리방침의 법적 사업자 정보·문의처 미확정
- 회원별 데이터 분리 및 비밀번호 재설정 E2E 테스트 미실시
- 관리자 요청 기록에 대한 실제 권한 테스트 미실시

주의: 현재 플러그인은 접수 기록만 저장한다. 삭제 요청 접수 = 계정 삭제 완료가 아니다.
