## 아직 검증하지 않은 실제 스테이징 흐름
1. 전용 테스트 회원 A/B 준비
2. 회원 A에 테스트용 관심 목록 저장, B에 별도 데이터 저장
3. WordPress 관리자 > 도구 > 개인정보 내보내기에서 A의 요청·이메일 확인·파일 생성·내용 확인
4. B의 데이터가 A 내보내기에 없는지 확인
5. 전용 테스트 회원 A만 WordPress 개인정보 삭제 절차 진행
6. A 관심 목록만 삭제되고 B는 유지되는지 확인
7. 개인정보 요청 양식 제출만으로 삭제가 일어나지 않는지 확인

## 운영상 주의
- 실사용 계정의 개인정보 삭제는 실행하지 않는다.
- 삭제 전 백업과 테스트 대상 식별이 필요하다.
- 개인정보 요청 페이지(ID 52)는 초안으로 유지한다.
- 회사 법적 정보와 개인정보처리방침이 확정되기 전에는 관련 페이지를 공개하지 않는다.
- 코드 수준 테스트 통과를 실제 E2E 검증 완료로 표현하지 않는다.
