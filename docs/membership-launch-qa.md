# SportIQ 이메일 회원가입 출시 전 검증

현재 스테이징: https://magnificent-taco-angel.wpcomstaging.com/

## 배포 게이트
- [ ] User Verification 설정에서 가입 이메일 인증을 필수로 설정
- [ ] 인증 전 로그인 차단이 실제로 작동하는지 확인
- [ ] 가입 인증 메일 발송자/제목/링크 및 유효기간 확인
- [ ] 메일 미수신 시 재발송과 만료 처리 확인
- [ ] 가입 남용 방지(속도 제한, 스팸 방지) 적용
- [ ] 개인정보처리방침의 운영자, 수집 항목, 보유 기간, 제3자 처리/국외 이전 정보 확정 후 게시
- [ ] 기본 가입 역할 Subscriber 확인
- [ ] 비밀번호 재설정 메일과 링크 정상 작동
- [ ] 인증 완료 계정으로 /my-favorites/에서 추가·삭제·재로그인 후 보존 확인
- [ ] 다른 계정에서 타인의 관심 목록이 보이지 않는지 확인
- [ ] 모바일 가입·로그인·관심 목록 화면 확인
- [ ] 사이트 소유자가 테스트 계정 및 테스트 이메일로 최종 승인

## 테스트 시나리오
1. 관리자에서 이메일 인증 강제와 인증 전 로그인 차단을 설정한다.
2. 테스트 기간에만 WordPress 일반 설정에서 신규 회원가입을 허용한다. 기본 역할은 Subscriber로 고정한다.
3. 새 테스트 이메일로 가입하고 인증 메일을 수신한다.
4. 이메일 인증 전에 로그인이 차단되는지 확인한다.
5. 인증 링크를 열어 계정을 인증한 후 로그인한다.
6. 관심 팀과 리그를 각각 저장하고 새로고침/재로그인 후 유지 여부를 확인한다.
7. 한 항목을 삭제하고 다른 계정으로 로그인해 데이터 격리를 확인한다.
8. 비밀번호 재설정을 수행한다.
9. 실패한 테스트는 회원가입을 다시 비활성화하고 원인을 수정한다.

## 현재 확인 가능한 상태
- User Verification 플러그인 활성화: 확인됨
- SportIQ Member Favorites 플러그인 활성화: 확인됨
- 신규 가입 허용 users_can_register: false
- 플러그인 내부 인증 정책과 메일 전달: 관리 도구로 확인 불가
- 가입 및 이메일 인증 E2E 테스트: 미실시

**주의:** 관리 도구는 users_can_register를 변경할 수 없으며, 인증 강제 여부를 추정해서 가입을 공개하지 않는다. 테스트 계정의 비밀번호를 GitHub나 대화에 저장하지 않는다.
