# SportIQ 개인정보 내보내기 스테이징 E2E 결과

- 플러그인: SportIQ Account Privacy Requests 0.2.0
- 대상: 스테이징 테스트 회원 A/B
- 결과 출처: 사용자 직접 수행·보고 (2026-11-14)
- 개인정보 확인 이메일 수신·승인: PASS
- 개인정보 내보내기 파일 생성: PASS
- 회원 A 관심 목록 포함: PASS
- 회원 B 관심 목록 미포함: PASS

## 판정
개인정보 내보내기 4개 항목 통과. 회원 A/B 관심 목록 분리 3개 항목도 앞선 사용자 테스트에서 통과 보고됨.

## 다음 단계: 삭제 테스트 전 안전 확인
1. 회원 A가 실제 계정이 아닌 폐기 가능한 테스트 계정인지 확인
2. 회원 A 관심 목록이 삭제되어도 괜찮은지 명시적으로 확인
3. 회원 B 계정·관심 목록은 보존
4. WordPress 도구 > 개인정보 삭제에서 **A 이메일만** 사용
5. 관리자 삭제 절차는 사용자가 직접 수행하고 결과를 기록
6. 요청 양식 제출만으로 삭제가 일어나지 않는지 별도 확인

**주의:** 아직 실제 개인정보 삭제 테스트는 실시하지 않았음. 사용자의 명시적 확인 전에는 삭제하지 않음.
